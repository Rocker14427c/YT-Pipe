# PipePipe UI preset

`PipePipe-YouTube-UI-Preset.zip` is a settings-only import profile for the modern YouTube-style PipePipe presentation.

## Import

1. Copy the ZIP to the device.
2. Open **Settings → Backup & restore → Import data**.
3. Select `PipePipe-YouTube-UI-Preset.zip`.
4. Confirm **Import settings**.
5. Restart PipePipe when the app asks.

The preset is intentionally a settings-only archive. It contains `newpipe.settings` and a `pipepipe.ui-preset` marker, but no `newpipe.db`. Importing it merges the selected preferences and does not replace subscriptions, history, playlists, downloads, cookies, or account data.

## Profile choices

- Device theme with layered dark mode
- Bottom navigation with Recommended, Subscriptions, and History
- Phone-friendly single-column list mode
- Modern search suggestions and filter sheet
- YouTube-style watch-page tabs: comments, related, and description
- Autoplay on Wi-Fi, 720p default playback, 480p popup playback
- Search and watch history enabled
- Swipe/brightness/volume/fullscreen playback gestures enabled
- SponsorBlock enabled with automatic segment handling
- Account cookies, proxy tokens, download paths, and service credentials excluded

The archive is generated by `tools/PipePipeUiPresetGenerator.java` and can be regenerated with:

```bash
javac -d /tmp/pipepipe-preset-gen tools/PipePipeUiPresetGenerator.java
java -cp /tmp/pipepipe-preset-gen PipePipeUiPresetGenerator presets/PipePipe-YouTube-UI-Preset.zip
```
